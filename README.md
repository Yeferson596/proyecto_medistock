# Medistock Frontend

Este branch contiene solo el frontend de Medistock.

## Ejecutar frontend

1. cd frontend
2. npm install
3. Crea `.env.local` si necesitas configurar la URL de la API
4. npm run dev

## Nota

- Usa el backend en la rama `main` o en otra ubicación separada.
- API base por defecto: `http://localhost:4000/api/v1`
